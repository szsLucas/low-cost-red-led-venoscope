# 3D enclosure — source files pending

The paper states that a two-part enclosure with a circular viewing aperture and controls was designed in Tinkercad and 3D-printed. No source file, STL, STEP, measured dimensions, material, print settings, tolerances, or assembly drawing were provided.

Requested files:

- Original Tinkercad design link or source export (with permission to share);
- printable STLs and, if possible, editable STEP/mesh design files;
- dimensioned drawings (outer dimensions, aperture diameter, LED-to-skin spacing);
- filament/material and print settings; mounting and wiring photos;
- safety/cleaning information suitable for a research-only prototype.

The images in `assets/figures/` come from the paper and are not a replacement for CAD files.

## Proposed final-revision finish and mechanical mask

Use a **matte-black enclosure** as the preferred finish (optical benefit not yet experimentally verified). Add an **opaque mechanical mask between the enclosure face and the PCB** to conceal LED solder joints while keeping each emitting surface and the central viewing opening clear. This is a physical cover/insert, not the PCB solder-mask layer. The mask's CAD geometry, fixing points, spacing, and electrical isolation must be documented and checked before any final build. These are planned improvements, not verified features of the existing assembly.
